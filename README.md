# Twoje Serce 🫀

Niezależny, oparty na dowodach naukowych przewodnik po zdrowiu układu krążenia: ciśnienie krwi, miażdżyca, stres i aspiryna.

**🔗 LIVE:** https://ttrader066-glitch.github.io/serce/

## O projekcie

Portal powstał z analizy **20 transkrypcji filmów YouTube** o zdrowiu serca (kardiologowie, lekarze medycyny prewencyjnej, popularyzatory nauki). Z materiałów wyekstrahowano **316 pojedynczych twierdzeń zdrowotnych**, z czego **176 zweryfikowano** w bazie PubMed (NCBI E-utilities) — wobec metaanaliz, systematycznych przeglądów i badań z randomizacją.

Każde twierdzenie dostaje werdykt: ✅ potwierdzone · ⚠️ częściowo prawdziwe · ❌ nieprawdziwe · ➖ niewystarczające dane — zawsze z numerem PMID i linkiem do abstraktu.

## Struktura strony

| Strona | Zawartość |
|---|---|
| `index.html` | Strona główna, kluczowe liczby, legenda werdyktów |
| `cisnienie.html` | Nadciśnienie: 12 przyczyn, 10 błędów pomiaru, ranking 12 metod obniżania (mmHg + CI) |
| `tetnice.html` | Miażdżyca: mechanizm blaszki, CANTOS, ApoB, Lp(a), K2 (VitaK-CAC), nattokinaza |
| `stres.html` | Stres i „ciśnienie oporne": oś HPA, kortyzol, oddychanie, sen, CPAP |
| `aspiryna.html` | Prewencja pierwotna vs wtórna: ASPREE, ASCEND, ARRIVE |
| `mity.html` | Najodważniejsze twierdzenia kontra badania (sól, keto vs DASH, cholesterol) |
| `zrodla.html` | Bibliografia: 71 unikalnych PMID, metodologia weryfikacji, lista materiałów |

## Stack

Statyczny HTML/CSS bez zależności. Design system pochodny od Mintlify: białe tło, akcent głębokiego teal (`#0F766E`), szeryfowe nagłówki Source Serif 4, JetBrains Mono do etykiet PMID. Hosting: GitHub Pages.

## Zastrzeżenie

Materiał edukacyjny — **nie zastępuje porady lekarskiej**. Decyzje o leczeniu (w tym aspirynie i lekach hipotensyjnych) podejmuj wyłącznie z lekarzem. Materiały źródłowe przywoływane w celu analizy krytycznej i edukacji.
